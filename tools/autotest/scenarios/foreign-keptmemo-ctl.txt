# removed: foreignpatch keptmemo wrong) and that use checked: the caller gets KeptOnly's own loop, the check finds the difference
# (logged), the memo turns off for the session and is faulted while the walk reuse itself stays on (foreignpatch keptmemo require
# off), and no memo is used after it (ListenerCache.WalkMemo the same) while walk outputs are still reused. ~945 cards.
expect ListenerCache: a memoized filtered walk differs from the filter run again over the same kept walk output
expect EFFECTCHECK ListenerCache\.WalkMemo grew since 'start': [0-9]+ -> [1-9]
expect EFFECTCHECK ListenerCache\.WalkMemo same since 'off'
