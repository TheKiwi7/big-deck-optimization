# HookFilter's cost color mirrors next to a walk-wrapping postfix (DESIGN "Cost colours next to a walk-wrapping patch",
# 2026-11-20). A postfix of "another mod" on CombatState.IterateHookListeners yields every Spiked Gauntlets twice
# (walk-expand-cost-postfix, RitsuLib's lazy shape: power cards cost 2 more, a cost-changing listener added by the postfix).
# ListenerCache's scopes serve with it let stand (augmented), where HookFilter's lists are never used: the cost color mirrors
# call the game's own walk and filter its output (HookFilter.EnergyCostColorWalk grows), and in this Debug build one answer in
# 64 is compared with the game's helper run vanilla (cost color mismatches 0: a mirror over the unpatched lists would miss the
# second gauntlets). The HookFilter walk back-off is a part of it now (Partly, not Inactive), with an exact note.
# A throw from the walk's code (hookfilter walkthrow: a step emitted into a dynamic assembly, in the helper's first walk, then in
# its second) is passed on as the game's helper throws it, after the same steps, no postfix run, HookFilter not faulted.
# Controls that must still back off (EnergyCostColorWalk stays the same): a no-op postfix on the AbstractModel default
# TryModifyEnergyCostInCombat (skipped calls would skip it), then a bool prefix on the helper at Priority.Last registered after
# the mirror (sorted after it).
timeout 900

expect FOREIGN hookfilter walkthrow plain: .*served over the game's walk
expect FOREIGN hookfilter walkthrow first walk: .*same as the game's
expect FOREIGN hookfilter walkthrow second walk: .*same as the game's

expect EFFECTCHECK ListenerCache grew since 'ctl1'
expect HookFilter: CardCostHelper\.TryModifyEnergyCostWithHooks is also patched by bdtest\.foreign\.bool-prefix \(postfixes and prefixes running before this mod's not enough\): normal game for that part
expect EFFECTCHECK HookFilter\.EnergyCostColorWalk same since 'ctl2': [0-9]+ -> [0-9]+
expect EFFECTCHECK ListenerCache grew since 'ctl2'
