# Co-op at <= 490 cards per player (host; client: coopsample-client.txt, parcoop.ps1 [-OnOff]): each peer imports the reference
# run, then trims its deck to 450 (bigdeck trim), so a combat holds ~900 cards in all and SnapshotVerifier's default Sample mode
# re-checks the game's own snapshots (after every action in co-op) against vanilla ones: above its MaxCombatCards (1,000 for the
# whole combat, every player's piles) it skips them, which every other co-op scenario is (945+ per player). Steps of
