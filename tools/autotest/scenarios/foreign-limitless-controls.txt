# The generic rules on the Limitless parts (2026-11-18): their controls, synthetic patches of another mod (Bench/ForeignShapesLimitless.cs)
# that must still back off, one at a time on its own chain method, each phase one combat start at ~945 cards (the reference deck,
# Limitless stacked enchantments) with LimitlessCloneMemo idle (its effect the same). Mod on only (nothing differs: each control's
# part stays the game's). FOREIGN runtime lines come from the runtime checks only.
# Rule A: (1) a postfix gated on an enchantment type on AbstractModel.MutableClone (it also runs on the inner card's enchantment:
# strict there), (2) a postfix gated on `is CardModel` on CardModel.AfterDeserialized (kept by TypeGated, but every inner card is
# a CardModel: the per-card strict check backs off; on AfterDeserialized, which every inner card's build runs: rule L judges
# UpgradeInternal only for an upgraded inner card), (3) a count before the gate's branch on CardModel.FinalizeUpgradeInternal
# (not a gate: TypeGated backs off; the enchantment group, which every stacked inner card reaches).
# Rule L (per content, Bench/ForeignShapesLimitless.cs `foreignpatch limitless reach`): strict count postfixes (Bench/ForeignPatches.cs
# count-postfix) on (l1) CardModel.AddKeyword: a Goopy content (its OnEnchant's closure reaches it) no longer kept, a Sharp or Clone one
# still is, the memo keeps running; (l2) NCard.FindOnTable (SoulsPower's closure only): Goopy and Sharp contents kept, the memo keeps
# running (SoulsPower contents are never kept next to BaseLib: its closure reaches powers' virtual methods BaseLib's abstract classes
# override); (l3) CardModel.get_MaxUpgradeLevel: a level-1 content no longer kept, a level-0 one still is.
# Rule B (copies of BaseLib's SavedSpireFieldPatch, Bench/ForeignShapesLimitlessTwins.cs, on SavedProperties.FromInternal):
# (b1) GetFieldsForModel without its filter, (b2) a null result stored, (b3) its class's initializer doing more than make the
# list, (b4) the accepted copy installed as a prefix, (b5) the accepted copy with its GetFieldsForModel patched, (b6) the accepted
# copy holding a field (registered for the rest of the session: last). Each backs off: LimitlessCloneMemo idle.
