# JoinMismatchNote (bdperf joinmsg, Bench/JoinMismatchBench.cs): the game's own mod mismatch error built from synthetic join
# lists, its description taken with the patch off and on: explained exactly when only this mod's entry differs (off against on,
# the "Co-op state check" tags, versions; the joining player only, the host's message on v0.111+ a control), the game's text alone otherwise, and
# every embedded language translated. Then with the whole mod off (bdopt off: this patch doesn't follow the master switch, the
# player whose mod is off needs it most), with another mod's postfix on GetErrorString sorted before this mod's (Priority.Last:
# it sees the game's text, kept, explained as without it; PostfixesBefore since 2026-11-18), then one sorted after it
# (priority 0 registered later: a back-off, the game's text alone), a passthrough postfix at the default priority (sorted
# before this mod's but run after it: Harmony runs the void postfixes first, a back-off), those postfixes removed again
# (explained again), and in French. No run, no network.
timeout 180
expect JOINMSG all \d+ cases ok, game language
expect JoinMismatchNote: NetErrorInfo\.GetErrorString is also patched by bdtest\.foreign\.noop-postfix \(postfixes running before this mod's: run around this mod's code as without it\): kept
expect JoinMismatchNote: NetErrorInfo\.GetErrorString is also patched by bdtest\.foreign\.noop-postfix \(postfixes running before this mod's not enough\): normal game for that part
expect FOREIGN classify NetErrorInfo\.GetErrorString: bdtest\.foreign\.noop-postfix Postfix .*priority 0: .*PostfixesBefore backs off \(postfix running after a postfix of this mod
expect JOINMSG all \d+ cases ok \(backoff
expect FOREIGN classify NetErrorInfo\.GetErrorString: bdtest\.foreign\.passthrough-postfix Postfix .*PostfixesBefore backs off \(postfix running after a postfix of this mod
expect JoinMismatchNote: NetErrorInfo\.GetErrorString is also patched by bdtest\.foreign\.passthrough-postfix \(postfixes running before this mod's not enough\): normal game for that part
expect JOINMSG all \d+ cases ok, game language fra
cmd bdperf joinmsg
cmd bdopt off
cmd bdperf joinmsg
cmd bdopt on
foreignpatch noop-postfix MegaCrit.Sts2.Core.Entities.Multiplayer.NetErrorInfo:GetErrorString

cmd bdopt why
foreignpatch remove
wait 3
foreignpatch passthrough-postfix MegaCrit.Sts2.Core.Entities.Multiplayer.NetErrorInfo:GetErrorString

cmd bdperf joinmsg backoff

cmd bdperf joinmsg
language fra
