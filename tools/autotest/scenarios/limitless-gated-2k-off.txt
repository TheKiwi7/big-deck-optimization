# A type-gated patch of another mod on the Limitless clone chain's card methods (CardModel.AddKeyword, a prefix doing nothing
# unless the card is a Squeeze: Bench/ForeignPatches.cs gated-prefix), three combat starts at ~945 cards (the reference deck,
# Limitless stacked enchantments). Mod off. Compare limitless-gated-2k-off and -on: CHECKSUM/STATE identical.
timeout 1500
cmd bdopt off
newrun NECROBINDER 1234
waitfor run 120
wait 2
cmd bigdeck import ref all all
# Priority 800: sorted before this mod's own prefix there (SnapshotCardReuse's write mark, default priority), as a mod patching
# at its load is (before this mod's deferred batches). Installed here at run time at the default priority, it sorted after that
# prefix and TypeGated rightly refused it (a gated prefix running after the mark could serialize the card before the write).
foreignpatch gated-prefix MegaCrit.Sts2.Core.Models.CardModel:AddKeyword squeeze priority 800
enemyhp 999999
immortal
cmd fight CULTISTS_NORMAL
waitfor idle 600
wait 1
checksum CULTISTS_NORMAL start
state CULTISTS_NORMAL start
play 5
waitfor idle 300
checksum CULTISTS_NORMAL plays
state CULTISTS_NORMAL plays
endturn
waitfor idle 600
checksum CULTISTS_NORMAL t1 end
state CULTISTS_NORMAL t1 end
cmd kill all
waitfor nocombat 300
wait 2
cmd fight KNIGHTS_ELITE
waitfor idle 600
wait 1
checksum KNIGHTS_ELITE start
state KNIGHTS_ELITE start
play 5
waitfor idle 300
checksum KNIGHTS_ELITE plays
state KNIGHTS_ELITE plays
endturn
waitfor idle 600
checksum KNIGHTS_ELITE t1 end
state KNIGHTS_ELITE t1 end
cmd kill all
waitfor nocombat 300
wait 2
cmd fight CULTISTS_NORMAL
waitfor idle 600
wait 1
checksum CULTISTS_NORMAL start
state CULTISTS_NORMAL start
play 5
waitfor idle 300
checksum CULTISTS_NORMAL plays
state CULTISTS_NORMAL plays
endturn
waitfor idle 600
checksum CULTISTS_NORMAL t1 end
state CULTISTS_NORMAL t1 end
cmd kill all
waitfor nocombat 300
wait 2
effects end
wait 1
foreignpatch remove
quit
