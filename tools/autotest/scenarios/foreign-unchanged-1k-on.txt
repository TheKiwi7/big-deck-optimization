# UnchangedTranspilers (A/B, mod on; DESIGN "Transpilers leaving the game's code unchanged"): Unlimited's PacketSizePatch shape
# (unchanged-transpiler: a list width 3 before WriteList/ReadList replaced by a call, none there) on every serializer
# RelicStateReuse and SnapshotCardReuse register, as Unlimited transpiles every public Serialize: kept, the relic reuse and the
# card bits run (effectcheck). A pure getter for a constant on CombatPileState.Serialize (getter-transpiler): refused, the pile
# bits back off. CHECKSUM and STATE lines identical with foreign-unchanged-1k-off. ~945 cards and the reference run's relics.
timeout 1500
expect UnchangedTranspilers: SerializableRelic\.Serialize: other mods' transpilers \(bdtest\.foreign\.unchanged-transpiler\) leave the game's code unchanged
expect UnchangedTranspilers: SavedProperties\.Serialize: other mods' transpilers \(bdtest\.foreign\.unchanged-transpiler\) leave the game's code unchanged
expect UnchangedTranspilers: RelicState\.Serialize: other mods' transpilers \(bdtest\.foreign\.unchanged-transpiler\) leave the game's code unchanged

expect UnchangedTranspilers: SerializableEnchantment\.Serialize: other mods' transpilers \(bdtest\.foreign\.unchanged-transpiler\) leave the game's code unchanged
expect UnchangedTranspilers: CombatPileState\.Serialize: other mods' transpilers \(bdtest\.foreign\.getter-transpiler\) refused \(instruction \d+ changed
expect SnapshotCardReuse: CombatPileState\.Serialize is also patched by bdtest\.foreign\.getter-transpiler
expect EFFECTCHECK RelicStateReuse grew since 'start': [0-9]+ -> [1-9]
expect EFFECTCHECK SnapshotCardReuse\.CardBits grew since 'start': [0-9]+ -> [1-9]
