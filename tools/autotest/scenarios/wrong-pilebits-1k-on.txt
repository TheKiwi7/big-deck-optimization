# Positive control: SnapshotCardReuse's check of a pile's kept header bits (PileSerializePostfix). Armed at the combat start (bdperf pilebits wrong): the next pass through that check
# sees a wrong answer, and must find it and take its fallback, which gives the game's own result: CHECKSUM and STATE lines
# (cardids included) must match wrong-1k-off line for line. ~945 cards; SnapshotVerifier off (bdperf verify off) so that
# this net, not the verifier, is the one that sees it. bdperf wrong check fails if the injection was never taken.
# When the net's detection falls inside a checksum's serialization, SnapshotVerifier's checksum postfix computes that checksum
# again from the game's serialization ("kept bits were found wrong while computing a checksum": the fallback's own path, not
# its sampled check; timing-dependent, proof run 2 saw it on both versions).
# compare-with: wrong-1k-off
expect SnapshotCardReuse disabled \(the bits kept for a pile differ from the game\'s\)
expect COUNTERS end:.*SnapshotCardReuse [^;]*\bverified \d+, mismatches [1-9]
expect SnapshotVerifier: a snapshot reuse was found wrong while building a snapshot: built again|SnapshotCardReuse disabled \(the bits kept|SnapshotVerifier: kept bits were found wrong while computing a checksum: computed again
timeout 900
newrun NECROBINDER 1234
waitfor run 120
wait 2
cmd bigdeck import ref all all
cmd bdperf verify off
enemyhp 999999
cmd fight CULTISTS_NORMAL
waitfor idle 600
wait 1
cmd bdperf pilebits wrong
checksum start
state start
play 3
waitfor idle 120
checksum t1 plays
endturn
waitfor idle 300
checksum t1 end
state t1
play 3
waitfor idle 120
checksum t2 plays
pilemove draw discard 2
wait 1
checksum moved
endturn
waitfor idle 300
checksum reshuffle
state reshuffle
play 3
waitfor idle 120
checksum t3 plays
state t3
cmd kill all
waitfor nocombat 300
wait 2
checksum after combat
state after combat
counters end
cmd bdperf wrong check
quit
