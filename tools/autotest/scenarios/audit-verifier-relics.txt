# Audit: what stays on after SnapshotVerifier finds a difference. A stale relic (relicreuse blind, the positive control) must be seen, and then
# EFFECT RelicStateReuse and the SnapshotCardReuse effects must stop growing: the verifier says every snapshot optimization is off
# (effectcheck fails the line otherwise).
expect SnapshotVerifier: (optimized snapshot differs from vanilla|line \d+: optimized)
expect verify mode: .*mismatches [1-9]
timeout 600
newrun NECROBINDER 1234
waitfor run 120
wait 2
enemyhp 999999
immortal
cmd relic add PEN_NIB
cmd relic add NUNCHAKU
cmd fight CULTISTS_NORMAL
waitfor idle 120
wait 1
cmd bdperf verify all
checksum start
effects start
cmd bdperf relicreuse blind on
cmd energy 50
play 3
waitfor idle 120
checksum t1
cmd bdperf verify
effects after mismatch
cmd bdopt
endturn
waitfor idle 120
checksum t2
play 2
waitfor idle 120
checksum t3
effects later
effectcheck RelicStateReuse same after mismatch
# The card reuse goes off with it (SnapshotVerifier turns SnapshotCardReuse off): none of its effects may grow either.
effectcheck SnapshotCardReuse.Cards same after mismatch
effectcheck SnapshotCardReuse.Piles same after mismatch
effectcheck SnapshotCardReuse.Moved same after mismatch
effectcheck SnapshotCardReuse.CardBits same after mismatch
effectcheck SnapshotCardReuse.PileBits same after mismatch
effectcheck SnapshotCardReuse.UpgradeBits same after mismatch
cmd bdperf verify
quit
