# clonememo-check with the memo's limit lowered to 4 (bdperf clonememocap; 16,384 saved contents otherwise, which no session
# reaches): the memo clears again and again while every answer is still compared byte for byte (bdperf clonememo verify 1), over
# three combats at 945 cards. Pass: verified about as many as cards with stacked enchantments,
# enabled True (a difference turns it off). Each `bdperf clonememo` report fails with verified 0 (the part never ran).
timeout 600
expect CLONEMEMOCAP limit 4, clears [1-9]
newrun NECROBINDER 1234

cmd bdperf checks off

cmd fight CULTISTS_NORMAL
waitfor idle 300
cmd bdperf clonememo
cmd kill all
waitfor nocombat 300
wait 3
cmd fight CULTISTS_NORMAL
waitfor idle 300
cmd kill all
waitfor nocombat 300
wait 3
cmd fight CULTISTS_NORMAL
waitfor idle 300
cmd bdperf clonememo
cmd kill all

cmd bdperf clonememocap
wait 2
