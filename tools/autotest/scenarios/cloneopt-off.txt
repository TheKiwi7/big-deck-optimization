# StS2 Clone Optimizer with this mod off: run before cloneopt-on (see there). bdopt off: the game's code, plus that mod.
timeout 1200
cmd bdopt off
newrun NECROBINDER
waitfor run 120
wait 2
cmd bigdeck import ref all all
cmd bigdeck import ref all all
rebuildcheck owners CloneRestSiteOption.OnSelect
checksum before
state before optional
# Game v0.114+: the clone option needs a card enchanted with Clone itself (nothing on an older game).
cmd bdclonable
cmd room RestSite
wait 5
restsite CloneRestSiteOption
waitfor deckcount 900
wait 10
checksum after
state after optional
counters clone
quit
