# Reflections event, Shatter (clones every deck card one by one, with a 0.1 s (fast) / 0.2 s (normal) wait each,
# none at Instant speed), ~1,880 cards (4 Bing Bongs: each clone copied again), speed instant; CHECKSUM to compare
# with reflections-instant-off.

wait 2
cmd bigdeck import ref all all
cmd bigdeck import ref all all
cmd bdperf checks off
cmd bdperf probe off

eventoption SHATTER 1500

gcstat shatter
waitfor deckcount 600
fpsstat

checksum after
