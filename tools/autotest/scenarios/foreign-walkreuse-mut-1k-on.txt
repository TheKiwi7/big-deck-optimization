# The rule of 2026-11-17 next to another mod's CombatStateChanged handler that changes what other mods' walk postfixes return
# (A/B, mod on; DESIGN "Owner-approved premises", Walks Tier 2): the shapes of foreign-walkreuse-1k-on plus a handler of "another
# mod", right after the hand's handler, flipping walk-expand-postfix's output at each call ("foreignpatch statechanged subscribe
# mutating afterhand": state no version bump sees). The outputs the hand kept are dropped after it (DroppedAfterForeign grew),
# each such key's next walk keeps a new output (KeptAfterForeign grew), none is reused across it, no kept output ever differs
# from a fresh one and the part stays on (require dropped: a missing drop shows there, and as a mismatch at a checked reuse).
# CHECKSUM and STATE identical with foreign-walkreuse-mut-1k-off; the expansion never ran on its own output (require nodouble).

expect EFFECTCHECK ListenerCache\.Walks\.KeptAfterForeign grew since 'start': [0-9]+ -> [1-9]
expect FOREIGN after other mods' handlers: kept anew [1-9][0-9]*, reused 0, walk mismatches 0, walk reuse on True
expect STATE foreign end statechanged-mutating calls [1-9]
expect FOREIGN walk-expand-postfix never ran on its own output
