# Another mod intercepting Harmony's reflection lookups for every caller (a cross-version compatibility mod's way): from the launch
# (launchforeign: --bdforeign, Bench/ForeignLaunch.cs, in before this mod applies anything), AccessTools.Method answers a hook of
# the other game version's name with this version's (BeforeTurnEnd and BeforeSideTurnEnd, AfterTurnEnd and AfterSideTurnEnd;
# v0.113's ModifyPreBlockDamageTarget with ModifyUnblockedDamageTarget), and
# AccessTools.Field answers the Mod field this version lacks (assembly or assemblies) with a stand-in giving every mod the core
# library. This mod's lookups go through the runtime (Reflect): every classified hook of this version is filtered, none left
# vanilla by a substituted hook, the substitutions logged apart; mods keep their names from the game's own Mod entry.
# Run on v0.111.1 (148 hooks) and v0.113.1 (154). HookSkip's table holds v0.111.1's and v0.113.1's rows only (since
# 2026-11-17): every name of a row is a v0.113.1 hook, so HookSkip's ignored substitution (ModifyPreBlockDamageTarget, a row
# v0.111.1 lacks) shows on v0.111.1 only; on v0.113.1 the alternatives below match its plain summary line.
timeout 300
launchforeign reflection-intercept
expect LAUNCHFOREIGN reflection-intercept: Harmony answers \w*TurnEnd -> \w*TurnEnd.*stand-in in place
expect HookSkip: (148 hooks filtered, 0 left vanilla \([1-9]\d* classified hooks not in this game version, [1-9]\d* lookups answered by another member, ignored\)|154 hooks filtered, 0 left vanilla \(0 classified hooks not in this game version\))
expect HookSkip: (ModifyPreBlockDamageTarget: Harmony's lookup answered by another member|154 hooks filtered, 0 left vanilla \(0 classified)
expect Harmony's reflection lookups are patched by bdtest\.foreign\.reflection-intercept
expect HookSkip: the game declares v[\d.]+; its code matches the tables of v[\d.]+
expect FOREIGN modname BaseLib: .+ \(mod entry\)
wait 5
foreignpatch modname BaseLib
cmd bdopt why
quit
