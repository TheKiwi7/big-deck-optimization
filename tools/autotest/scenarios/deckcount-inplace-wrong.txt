# Positive control of DeckCountMemo's free check outside the card redraw: a draw-pile card gets the Strike tag in place (its Tags
# set, as a content mod adding a tag does), with no pile move, after the memo counted Perfected Strike. In-redraw answers are
# never compared here (verify 1000000): only the check outside the redraw can see it. The play's damage must be the game's count
# ("bdperf deckcount gamecount strike": the last result outside the redraw equals a fresh count of the piles, the tagged card
# included) and the free check must turn the memo off (the expect lines).
expect DECKCOUNT inplace: .* tagged Strike in place
expect DeckCountMemo disabled, the game counts its cards: .*outside the card redraw
expect DECKCOUNT .*free mismatches [1-9]
timeout 300
newrun NECROBINDER 1234
waitfor run 120
wait 2
cmd bigdeck import ref all cards
cmd bdperf checks off
enemyhp 999999
immortal
cmd fight CULTISTS_NORMAL
waitfor idle 200
emptyhand
cmd bdperf deckcount verify 1000000
cmd card PERFECTED_STRIKE hand
wait 1
cmd bdperf deckcount answered strike
cmd bdperf deckcount inplace
playcard PERFECTED_STRIKE 0 free
waitfor idle 60
wait 1
cmd bdperf deckcount gamecount strike
onfail continue
cmd bdperf deckcount
quit
